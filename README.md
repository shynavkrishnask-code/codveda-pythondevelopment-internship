# Level 1 (Basic) - Python Development Internship @ Codveda

## Task 1: Simple Calculator (`calculator.py`)
- Separate functions for add, subtract, multiply, divide
- Menu-driven: choose an operation, enter two numbers
- Division by zero returns a clear error message
- Invalid numbers and menu choices are handled without crashing

Run: `python calculator.py`

## Task 2: Number Guessing Game (`number_guessing_game.py`)
- Uses the `random` module to pick a number from 1 to 100
- 7 attempts, with "Too high" / "Too low" feedback
- Validates input, ends on a correct guess or when attempts run out
- Option to play again

Run: `python number_guessing_game.py`
